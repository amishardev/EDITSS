# Dietary Guide · product ad campaign

Seven 9:16 films (1080x1920, 30 fps, H.264 + AAC, -14 LUFS), one per verified
product plus the Wellness Treat hero. Every claim on screen is copied from the
pack or the brand's own catalogue. Sources and what was left out are in
[`research/PRODUCT_BIBLE.md`](research/PRODUCT_BIBLE.md).

Each film follows HOOK → DESIRE → REVEAL → REASON → CTA. The films ship with
music, SFX and burned-in on-screen copy only. The Hinglish VO below is a
script for a voice artist to record over the existing timing, and the
on-screen text works as captions without it.

## Render

```bash
cd campaign
export REMOTION_BROWSER=/path/to/chromium   # only if Remotion cannot download its own
npm run render:products    # 7 MP4s into out/
npm run finish:products    # yuv420p, -14 LUFS, exact length, faststart
npm run qa:products      # verify specs + out/products-contact-sheet.jpg
npm run render:p07         # or one film (p01 ... p07)
```

The music is `public/audio/theme-p01..p07.m4a`, rebuilt with `npm run music`
(`scripts/compose.py`, original, no samples). Packshots are prepared with
`scripts/prepare_products.py` (see `research/ASSET_INVENTORY.md`).

The contact sheet for these films is `out/products-contact-sheet.jpg`.

## Missing or unverified assets

- **Prices, ratings and reviews:** prices show up in some sources (₹999, ₹149, ₹55), but they disagree and the live site was unreachable, so no price is shown anywhere.
- **Live website:** `dietaryguide.in` did not resolve from this environment. The CTA URL comes from the web repo routes, not a live check.
- **Mixed Seed carton:** the source cutout had a garbled "Net Weigl Seeds" print. That strip was rebuilt from the Almond carton's identical "Net Weight: 40g" artwork. Swap in a clean high-res carton scan when one is available.
- **Ingredients and full nutrition panels:** none were readable in the sources, so the films stick to the front-of-pack claims.
- **Wellness Treat contents:** taken from real photos of the opened box. The second jar and the tee/pouch aren't named in any spec sheet, so they're shown as "+ a little surprise".
- **Unwrapped bar macros:** there's only one lifestyle shot (`bars-scene.jpg`) for both bars. A dedicated macro of each bar would help 04 and 05.
- **Voiceover:** written above but not recorded. The films work silent, with captions only.
- **Digestion Tea claims:** the medical lines printed on the pack were not used in copy.
